# Maxwell Precision

Build a completely new, premium, modern website for **Maxwell Rubber Industry**, an automotive rubber parts manufacturing and exporting company.

The website must feel substantially different from a typical industrial/corporate website. Do NOT use the common design pattern of a full-screen factory image with text placed over it. The visual direction should feel like a **premium automotive component manufacturer / engineering brand**, combining industrial precision, editorial typography, product-focused presentation, and modern web design.

IMPORTANT:
Use the attached **Maxwell Rubber Industry Company Profile** as the primary source for company information and copy. Do not invent unsupported company facts, statistics, certifications, product names, clients, facilities, awards, or technical specifications. Where the supplied assets/content are insufficient, use clean placeholders or structure the section so actual assets/content can be added later.

5. HERO PRODUCT IMAGE SLIDER / ANIMATION
========================================

Implement a polished automatic product-image slideshow.

The hero product visuals should automatically change approximately every:

**2.5 to 3 seconds**

Sequence:

Product Image 01
→ Product Image 02
→ Product Image 03
→ Product Image 04
→ back to Product Image 01

Use the actual available Maxwell Rubber product images.

IMPORTANT:
The transition must be smooth and premium.

Do NOT use a basic hard-cut image swap.

Recommended animation behavior:

* Current product gently shifts/fades out
* Next product slides into position
* Slight scale-in from approximately 0.97 to 1
* Subtle opacity animation
* Supporting decorative elements transition smoothly
* No aggressive zoom
* No bouncing
* No flashy spinning
* No excessive parallax

The animation should feel similar to a premium automotive product presentation.

Timing:

* Auto change every 2500–3000ms
* Transition duration around 700–1000ms
* Use ease-in-out / cubic-bezier style transitions

Add small slide indicators such as:

01 / 04
02 / 04
03 / 04
04 / 04

The active indicator should update with the product.

Optional:
Add subtle previous/next controls that remain visually minimal.

On mobile:

* Keep product image visually large
* Reorganize the layered composition vertically
* Never allow product images to overlap important text
* Maintain smooth transitions

Respect:
`prefers-reduced-motion`

When reduced motion is enabled, use a simple fade or disable non-essential movement.
